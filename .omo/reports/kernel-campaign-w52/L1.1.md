## Decisions / deviations

1. **F9 test technique**: a fixed 5s busy-wait or a timed cross-process lock handoff would be a timing test, so the regression proves ordering behaviorally instead: the db file holds a non-SQLite payload, the first file-touching preflight read throws `SQLITE_NOTADB` (errno 26), and `PRAGMA busy_timeout` (connection-local, never touches the file) is then observed at 5000 on the same connection — provable only if the pragma ran strictly before the first preflight query. Covers both `preflightSqliteDatabase` and `initializeSqliteDatabase`. Verified pre-fix semantics manually: Bun's default busy_timeout is 0.
2. **L0Write shape**: implemented as a `const` object in `packages/ledger/src/index.ts` (no new module) because the five symbols live in two files (`sqlite-l0-write.ts`, `l0-hash.ts`) and no other file was in this lane's write scope. `export * as` over either module would leak non-surface symbols.
3. **Deviation — admission snapshot/decision types not exported**: plan §1 (F6) mentions "+ their snapshot/decision types", but `AdmissionSnapshot`/`AdmissionDecision` are not exported from `packages/agent/src/session-admission.ts`, and that file belongs to lane L3.2 (which the plan marks "**exported** (F6)"). This lane exported the function only; the type exports must land with L3.2. `RequestDecision` is already exported from `session-request.ts` for any consumer needing it.
4. `decideRequestTransition` was already exported from the agent index on this branch (no change needed).
