# L3.1 — ledger plane deletion (W5.2 #1197)

Branch `kernel/1197-session-entity-20260928`, worktree `/Users/ino/Develop/openomni-w52`.

## Outcome

Deleted the lease/alarm/inbox/migration planes from `packages/ledger` and
`packages/protocol`. The ledger is now two per-file stores (`openSessionStore`,
`openCatalogStore`) plus a kernel factory (`SessionHandleStore.createSessionKernel`);
the `Storage` singleton, `initialize`, `default-kernel.ts` TEMP shim,
`sqlite-storage.ts`, `sqlite-l0-adapter.ts`, the whole `migration/` directory,
`sqlite-schema-lifecycle.ts`, `sqlite-l0-alarms.ts`, `sqlite-l0-inbox.ts`,
`u967/u969/historical-*` and `l0-action-builders.ts` are gone. Lease RPCs
(`acquireLease`/`renewLease`/`releaseLease`, `LEASE_TTL_MS`, `HEARTBEAT_INTERVAL_MS`)
are replaced by single-shot `adoptFence` (CAS on `lease_fence`, `LeaseRefused
{reason:"stale", expiresAt:null}` on loss, idempotent re-adoption for the same
owner+fence). Inbox admission is replaced by the `pendingMessages` SQL projection
(prompt actions with inbox kind minus `inbox.deliver` matches). Protocol `l0.ts`
gained `AdoptFence`/`AdoptReceipt` and lost the lease/inbox/alarm request shapes;
`storage/index.ts` lost the corresponding sub-adapter seams.

## Deviations from plan

1. **Kept `Inbox.Commit` in protocol** — live consumers in `packages/channels`
   src and agent session-admission; deleting it was a planning gap. Flagged for
   L3.2/L3.3 owners.
2. **Kept `Alarm.Watch`/`WatchSpec`/`RetrySchedule`/`occurrenceId`** — consumed by
   monitor-ports, watch-sources and agent executor-attempts. Deleted
   `Alarm.RequestDeadline` and `openChildCount` everywhere.
3. **Deleted `test/storage/write-refusals.test.ts` entirely** — all 3 tests
   targeted the deleted alarm/inbox admission planes.
4. **Deleted `test/storage/fail-closed.test.ts`** — it tested the removed
   `Storage` singleton contract; per-domain fail-closed coverage lives in the
   `create*Store({})` tests in each domain suite.
5. **Dropped the "corrupt session ancestry" test** (storage-boundaries) — the
   ancestry walk lived in the deleted admission plane; per-file stores cannot
   validate cross-file ancestry.
6. **`sqlite-busy.test.ts`: dropped the two F9 preflight tests** —
   `initializeSqliteDatabase`/`preflightSqliteDatabase` are deleted; F9 bootstrap
   pragma-ordering coverage lives in `session-store.test.ts` and
   `catalog-store.test.ts`.
7. **Null-hash chain tests converted** — fresh schema has NOT NULL on
   `prev_hash`/`action_hash`, so tests assert constraint rejection instead of a
   broken-chain verdict.
8. **`bench/session-bench.test.ts`: dropped the spy-based commit-width tracking**
   — the kernel instance is created inside the bench entry point with no seam to
   spy; the machine-consumed metric-name emission assertions are retained.
9. **Regenerated `script/conformance/effect-runner-sites.json`** (224 → 54
   entries, net −170): stale entries for deleted ledger files removed, 8 moved
   ledger test/bench sites re-keyed. One removed entry is non-ledger
   (`packages/agent/test/helpers/retry-rearm-g3t.ts:19`) because the concurrent
   L3.2 lane deleted that file from the worktree.
10. **Fixed `packages/policy/test/row-fixtures.ts`** (unassigned in §3) — it
    imported the deleted `sqlite-storage`; ported to
    `openCatalogStore(":memory:").policies`. Policy suite 72 pass.
11. **Removed stale gitignored `packages/ledger/dist/` build artifacts** so the
    §5(a) grep is clean (source had zero hits either way).
12. **Exported `MaterializeInput`** from `src/session/kernel.ts` (TS4058 in the
    test helper return type) and `export type { DecisionFacts }` (type-only
    namespace; value export breaks under bun).
13. **`kernel.test.ts` capability-absent branches and the read-ports
    "missing storage capabilities fail closed" test dropped** — capability
    absence is impossible by construction with the store factories.
