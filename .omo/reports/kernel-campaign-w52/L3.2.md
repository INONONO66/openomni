## Deviations from the plan

- **L3.1 landed mid-flight in the shared worktree.** Early work was written
  against the target API blind (broken baseline); after L3.1's kernel landed,
  everything was re-verified against the real surface. `kernel.pendingMessages`
  exists and returns `Inbox.Row[]`, so `pendingBacklog` delegates to it instead
  of carrying a duplicate fold.
- **`listSessions` added to `SessionRuntime`** (not in the plan): the request
  port's cross-session `list()`/`timeout(requestId)` cannot be served by a
  per-session kernel. `findRequest` scans sessions O(n); acceptable for the
  current port, candidates for a catalog index later.
- **Out-of-turn request adoption always wins** (see Delivered 5) — the old
  expired-lease-only takeover has no analog without TTLs.
- **inspectSession children traversal** is kernel-scoped: `listRows()` comes
  from the catalog via the injected kernel, child action pages come from that
  kernel's session file. Cross-file child inspection degrades until an
  entity-side traversal exists (accepted in plan).
- **hibernate no longer waits for lease liveness** (there is none): the
  controller hibernates when quiescent (no active fiber, no raw slots, no
  pending backlog unless closed).
