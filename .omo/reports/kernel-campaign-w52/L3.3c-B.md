## Needs src

### S1 - `requestAuthorityKernel` decision runs under the wrong owner
`apps/openomni/src/composition/cluster-runtime.ts:444` +
`packages/agent/src/session-request.ts:162` (`ownsRequestRevision`).
The boot request port (`index.ts:276`) wraps `plane.openKernel` so commits
borrow the live activation's **fence**, but the pure decision still compares
`row.leaseOwner === command.authority.owner` with the caller's generated
`pid:request:*` owner -> every mid-turn `request.open`/transition in the booted
app is refused (surfaces as `CommitFailed` -> bare `ForeignFailure` at the tool
surface). Lane A recorded the same as "Latent bug (out of lane)".
Fix direction: when `liveTurns.get(sessionId)` has an entry, route request
transitions through `entry.ledger.transition(...)` (the seam A added for
`requests.timeout`), or mask `row()` in `requestAuthorityKernel` so the
borrowing caller reads itself as owner.

### S2 - `commitSessionRequest` folds the child-session admission into the sender's fenced batch
`packages/agent/src/session-admission.ts:356`. When `openNativeRequest` carries
`createSession` (every `new_session` send with deadline/replyTo binding), the
child session's admission actions (different `sessionId`) are appended to the
sender's single-session commit; `validActionBatch`
(`packages/ledger/src/storage/sqlite-l0-write.ts:113`) refuses the batch with
`CommitRefused {reason:"revision"}` even though revision and fence match.
Fix direction: filter foreign-session admission actions out of the sender
batch - they are committed separately via `ports.inbox.commit`. S1 masks S2 in
the booted app (S1 refuses first).

### S4 - shutdown join deadlocks on an ingest suspended on an open request
`apps/openomni/src/gateway.ts` `webSocketCallbacks.settled()` +
`apps/openomni/src/index.ts` `stop()` (lane A's seam 3). A ws text frame's
ingest runs the full turn inside the frame effect; a turn suspended inside a
protected tool wave awaiting a request answer never unwinds, so
`stop()` -> `await wsCallbacks.settled()` waits forever and the test harness
SIGKILLs the child (exit 137). Probe evidence (instrumentation added and fully
reverted; src is byte-identical to 7773bd09): `PROBE stage ws` then
`PROBE settled join, inflight: 1` with the pending frame being the original
`{"text":"Declare protected Person."}` prompt whose request was never approved.
Fix direction: after `boundServer.stop(true)` interrupt in-flight frame
effects (run them with an AbortSignal tied to stop) or bound `settled()` with
the terminal-`waiting` commit as the join point instead of effect completion.
Blocked: request-owner-e2e test 2 ("real Owner socket cannot apply ... changed
domain revision").
