### Root cause and fix

`analyze()` assigned every transitive `program.getSourceFile()` to the first
compiler project that loaded it. `packages/llm/src/provider/proxy-models.ts`
was therefore diagnosed under an importer's compiler options rather than its
own `packages/llm/tsconfig.json`; that native project passes `tsc --noEmit`.

The fix restricts candidate ownership and diagnostic collection to each
project's `program.getRootFileNames()`. A synthetic two-project regression
proves that a transitive source requiring its owning project's DOM library is
not diagnosed under the importer. The real-contract compiler assertion now
checks `analyze().sourceDiagnostics`, the same boundary used by the campaign.

The execution-copy fix also mirrors tracked working-tree deletions into the
detached snapshot before overlaying dirty files. Without this, concurrent W5.3
deletions reappeared from `HEAD`, producing ten false diagnostics in the first
local pilot. Its regression proves Git identity is retained while deleted
source bytes stay absent from nested execution copies.

Definitions:

- Cyclomatic complexity is one plus `if`, loops, `catch`, `case`, conditional
  expressions, and `&&`, `||`, `??` decisions in each function body. Nested
  function bodies are measured separately.
- Halstead difficulty is
  `(distinct operators / 2) * (total operands / distinct operands)` over
  TypeScript AST leaf tokens in each function body.
- CRAP is `cc^2 * (1 - cov)^3 + cc`, where `cov` is the fraction of that
  function's LCOV `DA` lines with positive hits.

Hand-computed fixture proof:

```ts
export function choose(a: number, b: number, flag: boolean) {
  if (flag) return a + b;
  return a - b;
}
```

- Cyclomatic: `1 + if = 2`.
- Halstead: operators `{return, +, -}` give `n1=3`; operands have `N2=5`,
  `n2=3`; difficulty `(3 / 2) * (5 / 3) = 2.5`.
- Synthetic LCOV covers one of the two executable lines, so `cov=0.5`;
  CRAP is `2^2 * 0.5^3 + 2 = 2.5`.
- Boundary fixture values exactly `22`, `80`, and `25` produce one finding
  each, proving the thresholds are exclusive.
