## Tests added (name + what would fail)

1. `session reads over the gateway socket > a page pointing at a next revision is followed with a cursor until the read drains`
   - Covers gateway-transport.ts:120-124. Real Bun.serve WebSocket answers a cursorless `session_read` with a snapshot whose `nextRevision: 2`; asserts the client sends the exact follow-up cursor `{ revision: 2, epoch: 2 }`, that subscribed listeners see both pages (`nextRevision` sequence `[2, null]`), and that `readSession` resolves on the terminal page only.
   - Fails if pagination stops (readSession never resolves -> timeout) or the cursor is wrong (exact `toEqual` on the received cursors). Mutant proof: `revision: frame.nextRevision + 1` -> fail (evidence/C2/mutant-pagination.txt, exit 1).
2. `... > a session-scoped error frame rejects that session's pending read`
   - Covers lines 151-153. Server answers the read with `{ type: "error", sessionId, reason: "session evicted" }`; asserts the read promise rejects with exactly that reason.
   - Fails if the reject path is skipped (timeout) or the reason fallback order changes. Mutant proof: dropping `frame.reason` from the message chain -> fail "session evicted" vs "session read failed" (evidence/C2/mutant-error-reason.txt, exit 1).
3. `... > a socket that closes mid-read rejects the pending read`
   - Covers lines 187-189 (drain rejecting pending reads). Waits for the server to receive the read frame (event, no sleep), then `server.stop(true)`; asserts rejection message is exactly "gateway socket closed unexpectedly".
   - Fails if drain skips pending reads (timeout) or the drain error text is dropped. Mutant proof: `drain(next)` without the message -> fail expected/received message mismatch (evidence/C2/mutant-drain-message.txt, exit 1).
4. `... > a send failure during a session read rejects instead of hanging`
   - Covers lines 215-216 (readSession send catch). Injected socket subclass throws on the `session_read` send; asserts the read rejects with the thrown error, not a hang.
   - Fails if the catch swallows or replaces the error. Mutant proof: `reject(new Error("gateway send failed"))` -> fail (evidence/C2/mutant-send-catch.txt, exit 1).
5. `session-time > a session with no durable page yet reads as not connected`
   - Covers reason.ts:29. Asserts `sessionReason(makeSession({ phase: null }), now) === "not connected"` exactly.
   - Mutant proof: returning "offline" -> fail (evidence/C2/mutant-reason.txt, exit 1).
