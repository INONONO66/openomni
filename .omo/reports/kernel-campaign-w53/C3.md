## Approach

Two root causes behind the assigned gaps:

1. **`if (import.meta.main) { ... }` block bodies** can never execute under `bun test` (LCOV
   records them `DA:n,0`), so every multi-line entry tail was dead weight for the gate. Verified
   empirically that a *single-line* guard (`if (import.meta.main) await runScriptMain(main);`)
   records a hit on plain import (probe: DA hit on the one-line form, DA:0 on the block body).
   Added a shared, fully tested helper `script/main-runner.ts` (`runScriptMain(run, exit =
   process.exit)`) and collapsed six entry tails onto it.
2. **Functions never invoked in-process** (tests that only spawn the script produce no LCOV).
   Added in-process tests that exercise each listed line through exported behavior.
