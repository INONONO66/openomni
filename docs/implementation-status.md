## Planned, not implemented

- Broader migration of legacy domain observations to L0 actions; the L0 action writer itself already commits before publishing through its injected observation sink.
- Dynamic component/plugin composition with reactive dependencies; reversible registration ownership ships as the app's composition substrate (`apps/openomni/src/composition/composer.ts`), which owns boot rollback and shutdown as one reverse-order release. The app-side driver and policy callback registries were deleted in #936: delegation drivers are now held directly by the kernel, and policy is a compiled immutable snapshot per generation (`packages/policy/src/row-compiler.ts`) that the hot path never re-reads. Channel surfaces are composed components: `apps/openomni/src/channels.ts` is a declarative profile (one row per configured channel), each row mounts as its own composition stage, and disposal revokes exactly what the component registered — its listener, its outbound delivery route (live-map registration read per delivery), and its surface-scoped `trusted_channel` grant (`registerTrustedChannelGrant`, which requires an explicit `defaultTier`: the row's declared `grant.defaultTier` or the least-authority `assigned_worker` mount tier — mounting a named surface never materializes owner authority, #931), so unmounted-channel traffic fails closed. Run policy is compiled rather than registration-owned (#936): `packages/policy/src/row-compiler.ts` compiles policy rows into one immutable snapshot per generation, mandatory rule classes (today `compaction`) are enforced at compile time so a generation missing one fails closed with a typed `mandatory_rule_missing` compile error, and the compiled snapshot supplies run-tightening verdicts only — admission verdicts remain solely with the gateway and delegation kernel. The production Resident path is covered end to end (`apps/openomni/test/resident-tool-executor-wiring.test.ts`): one delivery produces all eight `prompt`/`turn`/`llm`/`tool` pre and post decisions in the durable tree, with the tool intent parented to the turn envelope and its result parented to that intent, while prompt and turn decisions hang off the inbox action and envelope the session machine already committed rather than duplicating them. The shipped component events currently observe Resident/Worker invocation generations only.
- Connector installation/execution beyond retained protocol and storage primitives (#216 class).
- Memory.Engine / FTS5 session search (#220).
- P4 role surfaces (Governor, Jester, Voice).
- Stakes and effective-authority consumers; any such work must inherit their contracts rather than recreating legacy code.
