Every target command is `{version:1,inputId,sessionId,at,expectedRevision,authority,payload}`. Authority is authenticated ingress evidence for inbox admission; all owner writes carry `{owner,fence}`. Alarm evaluation additionally carries `{evaluatorOwner,evaluatorFence,expectedAlarmRevision}`. Times and authentication evidence are captured before DEC, and after any asynchronous authorization they are revalidated against the current snapshot. A decision returns either `{kind:"refused",code,receiptAction?}` or `{kind:"apply",expectedRevision,authority,actions,consumeInboxIds,regionPatch,effects}`. An effect descriptor is `{kind,causingActionId,idempotencyKey,payload}`. APPLY returns `{ok:true,revision,receipts,effects}` or the current `CommitResult` refusal shape. Revision/fence refusal never dispatches the decision's effects.

Events in the tables below name **commands**, not invented current exports. Current action kinds and fields are spelled out in section 6. New command payloads include all fields shown in their region product; `request.open` and `occurrence.open` carry the complete product with initial state. Result commands carry the identity, expected current state, terminal, reason/output, and captured time. Unknown versions, extra schema fields, absent identity, illegal source/event pairs, and inconsistent products are read-only `invalid_transition` from DEC. This final row makes each region table total: only explicitly listed transitions are admitted.

## 4. Original request, late input, and delivery

HEAD decision symbols are `attachReply` in protocol/wait/fold.ts, `approvals.answer` in agent/executor-approval.ts, `Approval.decide`/`decision` in protocol/approval/fold.ts, and delegation's nested `settle`/`settleFromReply`. Their different current persistence paths are in the receipts. In particular, HEAD Wait rejection calls `WaitStore.commit` but does not persist a Wait fact; it publishes ReplyRejected. `executeWaitRoute` lazily expires `deadline_passed` and writes `recordRouteNotDelivered`. HEAD `approvals.answer` rejects an expired answer even when its timer callback has not run. HEAD delegation `settleFromReply` has no deadline check of its own. REQUEST replaces these independent logical judgments at #969; these are not claims that the new receipts already ship.

**Target `request.answer_admission` is unconditional.** Capture authenticated receipt time from the owner clock, not the sender. After validating the session lease (no stale writer may even append a refusal), apply this order: equivalent processed `inputId` -> return its original receipt; divergent reuse -> read-only invalid_transition; `receivedAt >= deadline` -> `reply.late_unknown`, and if still open, expire the request in the same batch; before deadline, binding/principal/domain/input hash mismatch -> `reply.rejected`; terminal before deadline -> `reply.duplicate`; otherwise attach/resolve through the single open-state CAS. A late answer never reopens the old request and never becomes new inbox input, even if the timer is delayed. This explicitly supersedes logical post-terminal follow-up admission for this target. Physical reply correlation is still retained.

Send takes `{to,type,content,replyTo?,deadline?}` with authenticated sender separately; `new_session.parent` is `"me"`, resolved from that sender. ## 5. Alarm and occurrence transition product

Target authority is ALD/ALA/ALX through DEC/APPLY/DISPATCH. HEAD `sessionStopEvidence` only reads current actions/approvals/armed ids. `Alarm.Status` already lists four states, but there is no HEAD occurrence evaluator to cite or delete. The census assigns its existing evidence reader and alarm primitives to #971.

Canonical identities: `J` is sorted-key JSON encoding used by existing `canonicalDigest`; all keys below are **UTF-8 `canonicalKey` bytes**, not ad hoc string concatenation. Active key is `K([sessionId,kind,controlKey])`, where `controlKey` is the authenticated caller's stable monitor identity, stored in spec; a scheduled one-shot defaults to `K([fireAt,spec.value ?? null])`. Armed, paused, and fired-with-open-occurrence reserve this key. A cancelled or completed one-shot releases it. Rearm uses the same alarm id, increments epoch, and replaces its reservation atomically; another alarm reserving the key refuses `active_key_conflict`.

Transport duplicate identity is `(alarmId,epoch,sourceKey)`, with `sourceKey` captured from a timer fire slot or backend event/cursor. Repeating it returns the recorded occurrence receipt; differing payload under it refuses. Consecutive polling suppression is a separate tuple `(alarmId,epoch,lastBatchHash)`; equality produces a **new terminal deduped occurrence** only for a newly observed sourceKey. It does not overwrite the previous occurrence's terminal. Takeover preserves epoch, cursor and lastBatchHash. Explicit rearm increments epoch and clears lastBatchHash/cursor only according to the admitted source restart mode, so an explicitly restarted poll A may notify again. Wake key is `(destinationSessionId,occurrenceId)`; duplicate wake returns the original RCV receipt.

Every alarm control command includes `{alarmId,expectedAlarmRevision,epoch,at,owner,fence}`; every evaluator command includes those identity/revision fields plus `{evaluatorOwner,evaluatorFence,sourceKey,batchHash,cursorBefore,cursorAfter}`. Session lease is acquired before ALA mutates session actions, even while the session's runner sleeps. Evaluator lease alone cannot write session history. All control mutations fence evaluator callbacks by incrementing evaluator fence and clearing owner/expiry before physical cleanup.

### 6.6 Totality/property harness

HARNESS generates the Cartesian product of the finite region states and event tags above, and two-way permutations of contenders built against the same revision (reply/cancel/timeout; interrupt/answer; fire/pause/cancel; renew/takeover; duplicate input/result). Pure DEC is evaluated before APPLY; the loser is retried only as a **new decision against the winning snapshot**, never by dispatching its old proposal. Rejecting a late reply may append its explicit receipt; rejecting a stale lease cannot. For each accepted action prefix assert the named snapshot, exact next ordinal, terminal count per original result slot <=1, input-consumption count <=1, whole-wave gate body count 0, sequential-start barrier, and effect descriptor identity. Corrupt owner, fence, revision, parent session, input hash, generation, domain revision, cursor, deadline edge, and duplicate id independently; each must take the specified refusal branch. Replaying each exact prefix from its named seed must equal that prefix snapshot with dispatched effects `[]`. Refusal receipts are part of replay input, not silently discarded.

Before triggering asynchronous input, register the exact action-commit/runner-entry/body-settlement/abort/source-close signal; await that promise with a 2-second failure deadline. Time itself is advanced by the fixture clock and the captured timer callback, never by sleeping. For real app runs, register the socket response and storage observation before send; reopening file-backed SQLite must preserve the winning action and old immutable prefix. These are behavior assertions; documentation wording is not a test oracle.

### Receipt semantics

`move` removes the old writer at the same cutover as its exact target; `delete` has no consumer; `keep` preserves the current symbol at its source path. A parent row never includes a separately listed child. Every test symbol above is assigned to one sole child; in particular, positional history belongs to #972 and SQLite recovery belongs to #970, not both. `migrate` preserves identity and immutable evidence through a guarded forward migration; `refuse` retains bytes and rejects removal; `drop` is unused because no export/backup decision exists. The exact target test registrations named in section 6.7 are not silently counted as current symbols.

```python
    hits = subprocess.run(["rg", "-n", "-F", "--", needle, file],
                          check=True, capture_output=True, text=True).stdout
    assert any(int(first) <= int(hit.split(":", 1)[0]) <= int(last)
               for hit in hits.splitlines()), ("missing symbol", key, first, last)
    if kind == "prod":
        span = "\n".join(source[int(first)-1:int(last)])
        declared = (r"\b(?:function|class|interface|type|namespace|enum|const|let)\s+"
                    + re.escape(leaf) + r"\b|\b" + re.escape(leaf) + r"\s*\??\s*\(")
        # VariableDeclaration ranges begin after 'const'; its source line retains it.
        assert re.search(declared, span), ("not a declaration", key, first, last)
    count += 1
for file, first, last in re.findall(r"((?:packages|apps)/[\w/.-]+):(\d+)-(\d+)", text):
    lines = (root / file).read_text().splitlines()
    assert 1 <= int(first) <= int(last) <= len(lines), (file, first, last)
assert count > 0
print(f"{count} declared source/test symbols; duplicate receipt owners: 0")
```

The checker treats a qualified source symbol as one key even if multiple children use it. A deliberate duplicate row under another child must fail; an unknown symbol with an in-range line must fail. Neither formatting/lint nor this lexical checker alone proves transition semantics; section 6's behavioral vectors are the separately owned conformance oracle.
